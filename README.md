# Fiber Partner Hub

Рабочий кликабельный MVP-прототип управления строительством ВОЛС. Интерфейс демонстрирует полный цикл заявки, подбора и назначения партнера, строительства, контроля SLA и приемки.

## Запуск

Требуются Node.js 20.9+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`. Демо открывается сразу на Dashboard. Страница входа доступна из меню профиля → «Выйти из системы»; тестовая почта и пароль уже заполнены.

### Публичная демоверсия и QR-код

Откройте [Fiber Partner Hub](https://fiber-partner-hub.vercel.app). QR-коды ниже ведут на публичную демоверсию:

- [PNG для сканирования](./fiber-partner-hub-qr.png)
- [SVG для печати](./fiber-partner-hub-qr.svg)

Сайт развернут на Vercel из загруженной папки. Проект пока не подключен к GitHub для автоматической публикации после каждого push.

Для production-сборки выполните `pnpm build`, затем `pnpm start`.

## Реализованные функции

- Dashboard с 8 KPI, целевыми метриками TIME TO ASSIGN, TIME TO COMPLETE, SLA и LOST REQUESTS, очередью заявок и блоком эскалаций.
- Карта Казахстана на абстрактном SVG-провайдере: интерактивные заявки и партнеры, слои, фильтры по региону, городу, статусу, партнеру, типу, приоритету и просрочке.
- Реестр 1 284 заявок, карточки с прогрессом, SLA, полной историей событий, ресурсами и файлами.
- Создание заявки с адресом, техническими требованиями, сроками, приоритетом и документами. Новая заявка появляется в системе и на карте.
- Подбор TOP-3 по расстоянию (25%), свободной мощности (20%), рейтингу (15%), сроку выполнения (15%), квалификации (10%), технической готовности (10%) и стоимости (5%).
- Очередь предложений партнеру: принятие, отказ с передачей следующему кандидату и эскалация диспетчеру, если очередь исчерпана.
- Назначение бригады, продвижение по этапам, загрузка фото и документов, приемка и закрытие. KPI, загрузка партнера и доступность бригады обновляются в интерфейсе.
- Реестры партнеров, бригад, сотрудников, техники, оборудования, СИЗ, аккредитации и документов; карточка партнера и отдельный партнерский кабинет.
- Аналитика по статусам, месяцам, регионам, рейтингу и тепловой загрузке; центр уведомлений; экран RBAC-настроек.
- Адаптивные desktop, tablet и mobile layouts; состояние демонстрации сохраняется в `localStorage`.
- Демоданные: 20 партнеров (18 аккредитованы), 54 бригады (42 свободны), 108 сотрудников и 1 284 заявки. Объект `FPH-000124` соответствует примеру Завода ABC в Караганде.

## REST API

Все маршруты ниже доступны локально. API использует in-memory demo store, который сбрасывается при перезапуске сервера. UI-прототип хранит операции в браузере.

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка доступности |
| GET | `/api/requests?status=&region=&q=&limit=&offset=` | Фильтрованный реестр заявок |
| POST | `/api/requests` | Создать заявку |
| GET | `/api/requests/:id` | Карточка заявки |
| POST | `/api/requests/:id/assign` | Рассчитать TOP-3 и предложить партнера; можно передать `partnerId` |
| PATCH | `/api/requests/:id/status` | Изменить статус и добавить событие timeline |
| GET | `/api/partners` | Реестр партнеров |

Маршруты готовы для замены `demo-store` на репозитории Prisma и файловое объектное хранилище. Аутентификация API и межпользовательские ограничения в демонстрационном режиме не включены.

## База данных

`prisma/schema.prisma` описывает таблицы `User`, `Role`, `Partner`, `WorkRequest`, `Brigade`, `Employee`, `Resource`, `Document`, `TimelineEvent` и `Notification`. Поля `location` используют PostGIS `geometry(Point,4326)`. Для развертывания установите Prisma CLI/client, добавьте `DATABASE_URL` из `.env.example`, включите PostGIS и создайте миграцию.

## План production-развития

1. Подключить PostgreSQL/PostGIS, Prisma, миграции и транзакционное распределение ресурсов.
2. Заменить демо-вход на OIDC/SSO или session auth; применить серверный RBAC и изоляцию партнерских данных.
3. Подключить 2GIS/Mapbox/корпоративный GIS через map provider adapter, геокодер и дорожную матрицу расстояний.
4. Вынести назначение и двухчасовые таймеры в очередь задач; добавить уведомления email/SMS/push и эскалации.
5. Хранить файлы в S3-совместимом хранилище, проверять тип и размер, выдавать подписанные ссылки и вести аудит.
6. Подключить реальные источники ресурсов партнеров, мониторинг SLA, финансовые тарифы и импорт GIS/CRM/ERP.
7. Добавить серверную аналитику, журнал аудита, наблюдаемость, резервные копии и production security review.

## Границы демо

Карта схематическая, координаты и реестры синтетические. Файловые формы сохраняют названия выбранных файлов без передачи бинарных данных. REST API хранит изменения в памяти процесса; интерфейс хранит изменения в `localStorage`. Перед production-развертыванием подключите постоянную БД, object storage, auth и реальный GIS.
